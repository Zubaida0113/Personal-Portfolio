## Overview

This portfolio presents my technical background, featured projects, professional experience, education, achievements, and contact information in one responsive website.

It is designed to help recruiters, collaborators, and developers quickly understand my software-development experience, the technologies I work with, and how to connect with me.

## Features

- Responsive layout for desktop, tablet, and mobile devices
- Dark interface with pink gradient accents and animated background effects
- Sticky navigation, smooth section scrolling, and a mobile navigation menu
- Dynamic typing effect for professional roles
- About, Skills, Projects, Education, Experience, and Contact content
- Project filters for AI/Data and Web/Backend categories
- Social links for GitHub, LinkedIn, email, and LeetCode
- Contact form interface with toast feedback
- Reduced-motion support and accessible navigation label

> The contact form currently displays a confirmation toast; it does not send or store messages. Connect it to a form service or backend to receive submissions.

## Run Locally

Clone the repository:

```bash
git clone https://github.com/Zubaida0113/Personal-Portfolio.git
cd Personal-Portfolio
```

No package installation is required. Open `index.html` in a browser, or run a local server from the project directory:

```bash
python -m http.server 8000
```

Then visit <http://localhost:8000>.

## Deployment

### GitHub Pages

1. Push the project to a GitHub repository.
2. Open the repository's **Settings** and select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder, then save.
5. When deployment completes, add the published URL to the repository's About section and replace the live-demo placeholder above.
